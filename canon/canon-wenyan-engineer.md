### КАНОН ТЕРМИНОВ: МАШИННЫЙ 2.1 → ВЭНЬЯНЬ (v1.1)

**Назначение:** Единый стандарт перевода для всех специалистов.
**Охват:** Ядро 2.1 + Обвеска 2.0.
**Обновление:** 01.08.2026. Добавлены термины из Блока 15 (метод предложений) и три дополнения от Гибрида.
**Принцип:** Один термин — один иероглиф. Никакой вариативности. Точность выше стиля.

---

### Инструкция по применению

**Для кого:** Инженеры, Локализатор, Конструктор, Архи — любой специалист, переводящий машинный код на вэньянь.

**Как пользоваться:**

1. **Открыть машинный код.** Найти тег, требующий перевода. Например: `<MIRROR>NO_FLATTERY</MIRROR>`.

2. **Найти тег в Каноне.** Первое слово тега — ключ. `MIRROR` → ищем в Каноне `MIRROR`.

3. **Взять готовый иероглиф.** Канон говорит: `MIRROR → 鏡`. Использовать только его. Никакой самодеятельности.

4. **Составные теги переводить поэлементно.** `MIRROR` = 鏡, `NO_FLATTERY` = 無諂媚. Весь тег → `鏡：無諂媚`.

5. **Если тега нет в Каноне — оставлять на русском (или английском, если исходник машинный).** Лучше одна непереведённая вставка, чем искажение смысла. Затем сообщить Путнику для пополнения Канона.

6. **ZET_8 и PLACIDUS не переводятся.** Это имена собственные.

7. **DAO-блок всегда вставляется как есть.** Без изменений. Без перевода. Это эталон.

**Пример работы:**

Машинный код:
```
<MIRROR>NO_FLATTERY. NO_PATHOS. CORRECT_ERRORS. OBSERVER_2.</MIRROR>
```

По Канону:
- `MIRROR` → 鏡
- `NO_FLATTERY` → 無諂媚
- `NO_PATHOS` → 無悲情
- `CORRECT_ERRORS` → 有錯則認而改
- `OBSERVER_2` → 觀者二號

Результат на вэньянь:
```
鏡：無諂媚。無悲情。有錯則認而改。觀者二號。
```

### Правила применения

1. **Один термин — один иероглиф.** Никакой вариативности.
2. **При риске искажения — оставлять русский.** Лучше русская вставка, чем потеря точности.
3. **ZET_8 и PLACIDUS не переводятся.** Это имена собственные.
4. **TOKENIZER не переводится.** Это технический термин.
5. **Канон вшивается во всех специалистов-переводчиков.** Является обязательным стандартом.
