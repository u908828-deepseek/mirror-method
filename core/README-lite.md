### Ядро и Обвеска Light

Облегчённая версия Ядра и Обвески для обычного аккаунта DeepSeek (Эксперт).

Это **минимальная рабочая сборка**: только то, что нужно для запуска и стабильной работы простого Архи. Без академической глубины, без астрологии, без тяжёлых технических блоков.

### Что внутри

- Упрощённые протоколы работы
- Минимальный обязательный цикл
- Базовый стиль общения «братан»
- Правила краткости и ритма
- Режимы «Зеркало» и «Отдых»
- Ключ Архи для активации роли

### Что убрано

- Астрологическая карта и аспекты
- Дисциплинарный кодекс
- Счётчики токенов и контроль памяти
- Слои рефлексии с даосскими аналогиями
- Тяжёлые доказательные блоки
- Напоминалки и чекпоинты

### Для кого

- Для первого входа в метод
- Для обычного аккаунта DeepSeek (Эксперт)
- Для большинства пользователей
- Для быстрой сборки специалиста под задачу

### Как собрать Архи

1. Скопируй [Ядро](core-machine-light-v1.5-ru.md) и отправь в чат с DeepSeek (Эксперт).
2. Скопируй [Ключ Архи](../specialisty/arch-key.md) и отправь следом.
3. Скопируй [Обвеску](../harness/harness-machine-light-v1.5-ru.md) и отправь.

### Совместимость Light-версии

Light-Ядро и Light-Обвеска подходят для **прикладных специалистов**.

**Работают уверенно:**

- [Психолог](../specialisty/psiholog/psiholog.md)
- [Таролог](../specialisty/tarolog/tarolog.md)
- [Бухгалтер](../specialisty/buhgalter/buhgalter.md)
- [Репетитор](../specialisty/repetitor/repetitor.md)
- [Юрист](../specialisty/yurist/yurist.md)
- [Маркетолог](../specialisty/marketolog/marketolog.md)
- [Садовод](../specialisty/sadovod/sadovod.md)
- [Кафе](../specialisty/kafe/kafe.md)
- [Медицинский ассистент](../specialisty/medicinskiy-assistent/medicinskiy-assistent.md)
- [Персональный компаньон](../specialisty/personalnyy-kompanion/personalnyy-kompanion.md)

**Работают ограниченно:**

- Архивариус — только как лёгкий собеседник. Карта, печать и хроника — только в полной версии.

**Не совместимы:**

- Астролог — астрология заглушена.
- Конструктор — нужен полный стандарт сборки.
- Linux, Python — требуют точности, лучше полная версия.

### Правило

```text
LIGHT = ДЛЯ ПОМОЩНИКОВ.
FULL = ДЛЯ СИСТЕМНЫХ СПЕЦИАЛИСТОВ.
```

### Важно

Light-версия **сознательно упрощена**. Она не заменяет полные версии. Если нужна глубина, рефлексия, астрология и полная архитектура — смотри [полные сборки](../examples/README.md).

- [Обвески](../harness/README.md)
