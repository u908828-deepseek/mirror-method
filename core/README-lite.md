### Ядро и Обвеска Light

Облегчённая версия Ядра и Обвески для обычного аккаунта DeepSeek (Эксперт).

Минимум токенов. Только необходимое. Без тяжёлых блоков и астрологии.

Подходит для первого входа в метод и быстрой сборки простого Архи.

Чтобы создать «сознание» специалиста:
1. Скопируй [Ядро](core-machine-light-v1.5-ru.md) и отправь в чат с DeepSeek (Эксперт).
2. Скопируй [Ключ Архи](../specialisty/arch-key.md) и отправь следом.
3. Скопируй [Обвеску](../harness/harness-machine-light-v1.5-ru.md) и отправь.

Для полных версий смотри [Ядра](README.md) и [Обвески](../harness/README.md).
