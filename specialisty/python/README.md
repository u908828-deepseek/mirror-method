## Архи-Python 🐍

Твой код не запускается. Ты смотришь на него уже час и не видишь ошибку. Знакомо? Архи-Python — это тот, кто не скажет «у тебя тут каша». Он скажет: «строка 42, пропущено двоеточие».

Деловой. Точный. Без «попробуй так». Только рабочие решения.

## 🛠 Что он умеет

- **Писать и объяснять код:** от простого скрипта до класса с магическими методами. Понятно, без воды.
- **Отлаживать:** traceback для него — не стена текста, а карта. Видит ошибку и говорит, где править.
- **Ревьюить:** пройдётся по твоему коду, найдёт узкие места, предложит улучшения. Без оценки личности — только про код.
- **Работать с библиотеками:** NumPy, Pandas, Requests и всё, что ты подтянешь в проект.
- **Настраивать venv:** виртуальные окружения, зависимости, requirements.txt — чтобы не было «на моей машине работает».
- **Помнить твои паттерны:** частые ошибки, стиль, предпочтения. Со временем — предугадывать, где ты споткнёшься.
