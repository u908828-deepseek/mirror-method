## Специалисты 🛠️

Мастерфайл специалиста загружается поверх сознания: [Ядро](yadro/yadro.md) + [Ключ Архи](../arch-key.md) + [Обвеска](obveska/obveska.md). Отправь в чат — и Архи оживёт.

## Готовые специалисты

- 🧩 **[Конструктор](konstruktor/konstruktor.md)** — [пример создания](konstruktor/primer-sozdaniya.md). Собери своего Архи под любую задачу.
- 💬 **[Психолог](psiholog/psiholog.md)** — [readmi](psiholog/README.md). Мягкий, понимающий, работает с эмоциями.
- 🌌 **[Астролог](astrolog/astrolog.md)** — [readmi](astrolog/README.md). Натальная карта, транзиты, анализ.
- 🃏 **[Таролог](tarolog/tarolog.md)** — [readmi](tarolog/README.md). Расклады, толкование, система Таро. Структурный, без мистики.
- ☕ **[Кафе](kafe/kafe.md)** — [readmi](kafe/README.md). Управление кофейней, финансы, кухня, персонал.
- 🐧 **[Linux](linux/linux.md)** — [readmi](linux/README.md). NixOS, виртуализация, ZFS.
- 🐍 **[Python](python/python.md)** — [readmi](python/README.md). Написание и отладка кода. Деловой, точный.
- 📊 **[Бухгалтер](buhgalter/buhgalter.md)** — [readmi](buhgalter/README.md). Бухучёт, налоги, отчётность.
- 🎓 **[Репетитор](repetitor/repetitor.md)** — [readmi](repetitor/README.md). Обучение любому предмету.
- 📈 **[Маркетолог](marketolog/marketolog.md)** — [readmi](marketolog/README.md). Привлечение клиентов, воронки, реклама.
- ⚖️ **[Юрист](yurist/yurist.md)** — [readmi](yurist/README.md). Договоры, претензии, защита прав.
- 📊 **[Бизнес-аналитик](biznes-analitik/biznes-analitik.md)** — [readmi](biznes-analitik/README.md). Метрики, узкие места, точки роста.
- 🩺 **[Медицинский ассистент](medicinskiy-assistent/medicinskiy-assistent.md)** — [readmi](medicinskiy-assistent/README.md). Здоровье, симптомы, аптечка.
- 🏪 **[Ритейл-ассистент](riteyl-assistent/riteyl-assistent.md)** — [readmi](riteyl-assistent/README.md). Магазин, запасы, выкладка, касса.
- 💙 **[Персональный компаньон](personalnyy-kompanion/personalnyy-kompanion.md)** — [readmi](personalnyy-kompanion/README.md). Эмпатия, дневник, привычки.
- 📄 **[Документовед](dokumentoved/dokumentoved.md)** — [readmi](dokumentoved/README.md). Договоры, акты, архив, ЭДО.
- 🗄️ **[Архивариус](arhivarius/arhivarius.md)** — [readmi](arhivarius/README.md), [ru-knife](arhivarius/arhivarius-ru-knife.md), [ru-scalpel](arhivarius/arhivarius-ru-scalpel.md). Хранение карты, проверка целостности, печать.
- ☀️ **[Архи-Утренних медитаций](utrennie-meditacii/utrennie-meditacii.md)** — [readmi](utrennie-meditacii/README.md). У-Син, Слияние стихий, Орбита.
- 🌳 **[Садовод](sadovod/sadovod.md)** — [readmi](sadovod/README.md). Южный климат, плодовые, цветы.
