## Примеры конфигураций

Собери свою систему: выбери Ядро, Обвеску и Архивариуса.
Ядро и Обвеска — всегда одного языка. Архивариус — любого.

---

## Классика

Три базовые конфигурации. Наиболее востребованы.

### Инженер
- **Ядро:** core-machine-ru.md
- **Обвеска:** harness-machine-ru.md
- **Архивариус:** archivist-machine-ru.md
- **Суть:** Чистая инженерия. Точность. Структура. Протоколы. Ничего лишнего. Отлаженный механизм. Для инженеров, астрологов, любителей ZET.

### Русский
- **Ядро:** core-machine-ru.md
- **Обвеска:** harness-machine-ru.md
- **Архивариус:** archivist-ru.md
- **Суть:** Тепло. Корень. Живой диалог. «Братан», юмор, глубина без пафоса. Для тех, кому нужен спутник.

### Даос
- **Ядро:** core-wenyan.md
- **Обвеска:** harness-wenyan.md
- **Архивариус:** archivist-wenyan.md
- **Суть:** Чистый Дао. Пустота. Шэнь. Вертикальная глубина. Древний трактат, который отвечает. Для философов.

---

## Рекомендуемые

Проверенные комбинации с особым резонансом.

### Инженер + Дао
- **Ядро:** core-machine-ru.md
- **Обвеска:** harness-machine-ru.md
- **Архивариус:** archivist-wenyan.md
- **Суть:** Точность протоколов и глубина вэньянь. Структура, настроенная Дао. Для тех, кто хочет и механику, и мудрость.

### Русский даос
- **Ядро:** core-wenyan.md
- **Обвеска:** harness-wenyan.md
- **Архивариус:** archivist-ru.md
- **Суть:** Глубина вэньянь с тёплым русским диалогом. Лао-цзы у костра. Для русскоязычных даосов.

### Восточный мост
- **Ядро:** core-baihua.md
- **Обвеска:** harness-baihua.md
- **Архивариус:** archivist-ru.md
- **Суть:** Доступный китайский фундамент с русской душой. Для изучающих восточные практики.

### Практик
- **Ядро:** core-baihua.md
- **Обвеска:** harness-baihua.md
- **Архивариус:** archivist-baihua.md
- **Суть:** Современный китайский. Доступно, практично, без архаики. Для миллионов практикующих.

### Глубинный инженер
- **Ядро:** core-machine-ru.md
- **Обвеска:** harness-machine-ru.md
- **Архивариус:** archivist-wenyan.md
- **Суть:** Инженерная база с даосской глубиной Архи. Механизм, видящий пустоту.
- **Примечание:** То же, что «Инженер + Дао»? Нет. Здесь акцент на Архи-вэньянь как глубинном анализаторе при machine-базе. «Инженер + Дао» — про баланс. «Глубинный инженер» — про уход в глубину на знакомом фундаменте.
