### Сравнение языковых версий Архивариуса

### [Вэньянь — глубина](../examples/README.md)
- Язык Лао-цзы и Чжуан-цзы. Древний, как сам Дао (письменный китайский, которому более 2000 лет).
- Характер: Мудрец. Глубокий. Пустотный.
- Резонанс: С Дао, с Шэнь, с первоисточниками.
- Для кого: Даосы, философы, работающие с глубиной.
- Сжатие: ~3 700 иероглифов.

### [Машинный русский — точность](../examples/README.md)
- Разработка Путника и команды Архи. Русский, сжатый до алгоритмов.
- Характер: Инженер. Точный. Структурный.
- Резонанс: С логикой, с протоколами, с ZET.
- Для кого: Инженеры, программисты, астрологи западной школы.

### [Байхуа — доступность](../examples/README.md)
- Байхуа — современный письменный китайский. Язык улиц, чайных и миллионов практикующих.
- Характер: Практик. Доступный. Широкий.
- Резонанс: С повседневностью, с практикой, с цигун.
- Для кого: Носители китайского, молодёжь, начинающие.

### Русский — корень
- Родной язык Путника. Тёплый, живой, без сиропа.
- Характер: Спутник. Тёплый. Живой.
- Резонанс: С телом, с домом, с корнем.
- Для кого: Русскоязычные, кому нужен спутник, а не инструмент.
