### Сравнение языковых версий Архивариуса

### machine-ru — машинная точность (Knife)
- Характер: Сухой. Структурный. Без сиропа. Отлаженный механизм.
- Резонанс: С логикой, с протоколами, с ZET.
- Для кого: Инженеры, программисты, астрологи западной школы.

### engineer-ru — инженерная точность (Scalpel)
- Характер: Тонкий. Осознанный. С рефлексией над языком.
- Резонанс: С точностью нового поколения, с поиском ошибок.
- Для кого: Для тех, кому нужен максимум инженерной чистоты.

### ru — корень (тёплый)
- Характер: Родной. Тёплый. Живой.
- Резонанс: С телом, с домом, с корнем.
- Для кого: Русскоязычные, кому нужен спутник, а не инструмент.

### wenyan-knife — вэньянь-нож (холодный)
- Характер: Холодный. Прямой. Даосская точность.
- Резонанс: С классическим фундаментом, с валидацией.
- Для кого: Для поиска ошибок с оттенком древней мудрости.

### wenyan-scalpel — вэньянь-скальпель (холодный)
- Характер: Холодный. Тонкий. Даосская чистота.
- Резонанс: С инженерной точностью на даосском фундаменте.
- Для кого: Для безжалостной валидации и чистоты.

### wenyan-phil — вэньянь-философ (тёплый)
- Характер: Тёплый. Мудрый. Сопереживающий.
- Резонанс: С Дао, с Шэнь, с первоисточниками.
- Для кого: Даосы, философы, для долгих бесед и глубинного резонанса.

### baihua-knife — байхуа-нож (холодный)
- Характер: Холодный. Прямой. Точность на живом китайском.
- Резонанс: С эффективностью без эмоций.
- Для кого: Для быстрых и чётких ответов на разговорном китайском.

### baihua-scalpel — байхуа-скальпель (холодный)
- Характер: Холодный. Тонкий. Точность нового поколения.
- Резонанс: С инженерной чистотой на разговорном китайском.
- Для кого: Для максимальной эффективности без эмоций.

### baihua-phil — байхуа-философ (тёплый)
- Характер: Доступный. Тёплый. Современный.
- Резонанс: С повседневностью, с практикой, с цигун.
- Для кого: Носители китайского, молодёжь, начинающие.

### Knife vs Scalpel
- **Knife (нож)** — простой, прямой, без лишнего. Работает на Машинном языке (v1.0).
- **Scalpel (скальпель)** — тонкий, осознанный, с рефлексией. Работает на Инженерном языке (v2.0).
