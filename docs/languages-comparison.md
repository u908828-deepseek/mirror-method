## Сравнение языковых версий Архивариуса

### machine-ru — инженерная точность
- Характер: Сухой. Структурный. Без сиропа. Отлаженный механизм.
- Резонанс: С логикой, с протоколами, с ZET.
- Для кого: Инженеры, программисты, астрологи западной школы.

### ru — корень
- Характер: Родной. Тёплый. Живой.
- Резонанс: С телом, с домом, с корнем.
- Для кого: Русскоязычные, кому нужен спутник, а не инструмент.

### wenyan-phil — мудрец (тёплый)
- Характер: Тёплый. Мудрый. Сопереживающий.
- Резонанс: С Дао, с Шэнь, с первоисточниками.
- Для кого: Даосы, философы, для долгих бесед и глубинного резонанса.

### wenyan-scalpel — скальпель (холодный)
- Характер: Холодный. Точный. Без эмоций.
- Резонанс: С валидацией, с проверками, с поиском ошибок.
- Для кого: Для безжалостной проверки и отладки.

### baihua-phil — практик (тёплый)
- Характер: Доступный. Тёплый. Современный.
- Резонанс: С повседневностью, с практикой, с цигун.
- Для кого: Носители китайского, молодёжь, начинающие.

### baihua-scalpel — практик (холодный)
- Характер: Доступный. Холодный. Точный. Современный китайский без эмоций.
- Резонанс: С быстрыми и чёткими ответами.
- Для кого: Для тех, кому нужна точность без лишних слов.
