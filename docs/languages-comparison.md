## Архивариусы 🗄️

Девять специалистов. Выбери под задачу.

### Холодные — для точности

**Knife (нож)** 🔪 — машинная точность. Простой, прямой, без лишнего. Режет прямо. Machine (v1.0).

| Архивариус | Характер | Резонанс | Для кого |

| **[wenyan-knife](../specialisty/arhivarius/arhivarius-wenyan-knife.md)** | Холодный. Прямой. Даосская точность. | С классическим фундаментом, с валидацией. | Для поиска ошибок с оттенком древней мудрости. |
