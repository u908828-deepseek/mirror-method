### Архивариусы

Девять специалистов. Выбери под задачу.

### Холодные — для точности

**Knife (нож)** — машинная точность. Простой, прямой, без лишнего. Режет прямо. Работает на Машинном языке (v1.0).

| Архивариус | Характер | Резонанс | Для кого |
|:---|:---|:---|:---|
| **machine-ru** | Сухой. Структурный. Без сиропа. Отлаженный механизм. | С логикой, с протоколами, с ZET. | Инженеры, программисты, астрологи западной школы. |
| **baihua-knife** | Холодный. Прямой. Точность на живом китайском. | С эффективностью без эмоций. | Для быстрых и чётких ответов на разговорном китайском. |
| **wenyan-knife** | Холодный. Прямой. Даосская точность. | С классическим фундаментом, с валидацией. | Для поиска ошибок с оттенком древней мудрости. |

**Scalpel (скальпель)** — инженерная точность. Тонкий, осознанный, с рефлексией. Оперирует тонко. Работает на Инженерном языке (v2.0).

| Архивариус | Характер | Резонанс | Для кого |
|:---|:---|:---|:---|
| **engineer-ru** | Тонкий. Осознанный. С рефлексией над языком. | С точностью нового поколения, с поиском ошибок. | Для тех, кому нужен максимум инженерной чистоты. |
| **baihua-scalpel** | Холодный. Тонкий. Точность нового поколения. | С инженерной чистотой на разговорном китайском. | Для максимальной эффективности без эмоций. |
| **wenyan-scalpel** | Холодный. Тонкий. Даосская чистота. | С инженерной точностью на даосском фундаменте. | Для безжалостной валидации и чистоты. |
